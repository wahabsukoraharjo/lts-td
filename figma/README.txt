MATERI FIGMA — HTML SLIDE DECK

Buka index.html untuk memilih sesi.
Setiap sesi memiliki 18 slide dan dapat dijalankan offline. Google Fonts bersifat opsional; jika tanpa internet, font sistem akan digunakan.

Kontrol:
- Arrow Right / Space / PageDown: slide berikutnya
- Arrow Left / PageUp: slide sebelumnya
- Home / End: slide pertama / terakhir
- M: buka daftar isi
- F: fullscreen
- Swipe kiri/kanan pada perangkat sentuh

File figma_html_manifest.json disediakan untuk integrasi ke training portal.
