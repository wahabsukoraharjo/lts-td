FIG-S03 • Core Concepts

Definisi Auto Layout

Makna setiap istilah dan cara menggunakannya dalam praktik

Slide 8

Auto Layout

Fitur Figma yang mengatur posisi dan ukuran anak secara otomatis berdasarkan arah, gap, padding, alignment, dan resizing.

Direction

Arah penyusunan item secara horizontal, vertikal, atau wrap.

Padding

Ruang di antara batas container dan konten di dalamnya.

Gap

Jarak antarelemen di dalam Auto Layout.

Definisi operasional untuk praktik dan review

Definisi Resizing

Makna setiap istilah dan cara menggunakannya dalam praktik

Slide 9

Hug Contents

Ukuran objek mengikuti total ukuran konten di dalamnya.

Fill Container

Objek mengisi ruang tersedia di parent Auto Layout.

Fixed Size

Ukuran objek dipertahankan pada nilai tertentu.

Min/Max Size

Batas minimum atau maksimum ukuran objek agar tetap usable pada berbagai konten.

Definisi operasional untuk praktik dan review

Definisi Nested Layout & Constraints

Makna setiap istilah dan cara menggunakannya dalam praktik

Slide 10

Nested Auto Layout

Auto Layout di dalam Auto Layout lain untuk membangun struktur kompleks secara modular.

Constraints

Aturan posisi/ukuran objek saat frame parent berubah ukuran, misalnya left-right, center, top-bottom, atau scale.

Absolute Position

Objek dikeluarkan dari alur Auto Layout untuk ditempatkan bebas relatif terhadap parent.

Clipping

Pemotongan konten yang keluar dari batas frame.

Definisi operasional untuk praktik dan review

Definisi Responsive Design

Makna setiap istilah dan cara menggunakannya dalam praktik

Slide 11

Responsive Design

Pendekatan yang membuat layout menyesuaikan ruang, perangkat, dan variasi konten.

Breakpoint

Rentang ukuran layar yang memicu perubahan struktur layout.

Content Stress Test

Pengujian komponen menggunakan teks pendek, panjang, kosong, atau jumlah item berbeda.

Adaptive Pattern

Perubahan pola layout untuk konteks berbeda, misalnya sidebar desktop menjadi bottom navigation pada mobile.

Gunakan: Button, badge, chip, tag.

Common Mistakes & Best Practice

Kesalahan yang perlu dihindari selama praktik

Slide 16
DON'T
  • Mengunci semua elemen dengan Fixed size.
  • Menumpuk terlalu banyak frame tanpa hierarchy yang jelas.
  • Tidak menguji label panjang, kosong, atau dua baris.
DO
  • Mulai dari komponen kecil lalu susun nested layout.
  • Gunakan Hug untuk komponen berbasis isi dan Fill untuk area fleksibel.
  • Stress test pada ukuran mobile dan desktop.
Review before submit

Troubleshooting Guide

Gejala, penyebab, dan tindakan perbaikan

Slide 17
GejalaPenyebab UmumSolusi
Button melebar tidak wajarParent/child memakai Fill yang salahGunakan Hug untuk button dan Fill hanya pada konteks full-width.
Text keluar dari cardWidth/height fixed atau wrapping tidak tepatGunakan Fill/Hug yang sesuai dan izinkan text membungkus.
Nested layout sulit dipahamiHierarchy terlalu dalam dan nama frame tidak jelasSederhanakan layer dan beri nama berdasarkan fungsi.

Digital Tele-interview System

Prototype antarmuka digital untuk mencatat aktivitas magang, pembelajaran, hambatan, solusi, bukti hasil kerja, feedback mentor, dan tindak lanjut pada setiap sesi.

Bentuk Deliverable

Pada bulan Figma, deliverable berupa prototype high-fidelity interaktif—bukan aplikasi produksi—yang menunjukkan struktur, alur, state, dan pengalaman pengguna.

Hubungan dengan Program

Prototype menjadi rancangan pengalaman yang dapat dijadikan acuan ketika fungsi serupa dikembangkan pada modul web Laravel, API Java Spring Boot, atau aplikasi Flutter.
