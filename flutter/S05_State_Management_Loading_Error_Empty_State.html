Slide 19
learning_log_notifier.dartDART
enum LoadStatus { initial, loading, success, empty, error }

class InterviewScheduleNotifier extends ChangeNotifier {
  InterviewScheduleNotifier(this.repository);

  final InterviewScheduleRepository repository;
  LoadStatus status = LoadStatus.initial;
  List<InterviewSchedule> items = [];
  String? message;

  Future<void> load() async {
    status = LoadStatus.loading;
    notifyListeners();
    try {
      items = await repository.fetchAll();
      status = items.isEmpty ? LoadStatus.empty : LoadStatus.success;
    } catch (_) {
      message = 'Data belum dapat dimuat';
      status = LoadStatus.error;
    }
    notifyListeners();
  }
}

state_view.dartDART
Widget buildBody(InterviewScheduleNotifier state) {
  return switch (state.status) {
    LoadStatus.initial => const SizedBox.shrink(),
    LoadStatus.loading => const Center(child: CircularProgressIndicator()),
    LoadStatus.empty => const EmptyTele-interviewView(),
    LoadStatus.error => ErrorView(
        message: state.message ?? 'Terjadi kesalahan',
        onRetry: state.load,
      ),
    LoadStatus.success => RefreshIndicator(
        onRefresh: state.load,
        child: InterviewScheduleList(items: state.items),
      ),
  };
}

Best Practice

Praktik yang perlu dipertahankan

Slide 26
  • Buat state eksplisit, bukan banyak boolean terpisah.
  • Pisahkan UI rendering dari logic fetching.
  • Uji semua state, bukan hanya success.
  • Gunakan pesan error yang bisa ditindaklanjuti pengguna.

Common Mistakes

Kesalahan yang sering menurunkan kualitas aplikasi

Slide 27
  • Menggunakan isLoading, hasError, isEmpty tanpa konsistensi.
  • Menampilkan spinner tanpa batas saat request gagal.
  • Error teknis mentah ditampilkan ke pengguna.
  • Tidak ada cara retry.
