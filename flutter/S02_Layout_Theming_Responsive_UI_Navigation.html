SLIDE 14
responsive_dashboard.dartDART
class DashboardBody extends StatelessWidget {
  const DashboardBody({super.key});

  @override
  Widget build(BuildContext context) {
    return LayoutBuilder(
      builder: (context, constraints) {
        final wide = constraints.maxWidth >= 760;
        final summary = const SummaryPanel();
        final list = const LearningLogList();

        return wide
            ? Row(children: [Expanded(child: summary), Expanded(child: list)])
            : ListView(children: [summary, const SizedBox(height: 16), list]);
      },
    );
  }
}

Best Practice

Praktik yang perlu dipertahankan

SLIDE 19
  • Pahami constraints sebelum menambah banyak Container.
  • Gunakan ThemeData, bukan warna hardcode di banyak widget.
  • Buat route name atau struktur navigasi yang mudah dipelihara.
  • Uji UI di minimal dua ukuran layar.
Program Magang Developer • Flutter • FLT-S02

Common Mistakes

Kesalahan yang sering menurunkan kualitas aplikasi

SLIDE 20
  • Membungkus semua widget dengan Container tanpa alasan.
  • Menggunakan fixed width yang rusak di layar kecil.
  • Duplikasi style di setiap halaman.
  • Navigation tidak memiliki skenario back yang jelas.
